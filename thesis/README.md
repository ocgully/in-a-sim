# Thesis package

The final output of the project: one report, one long-form video, one social series.

| path | contents |
|---|---|
| [`report/THESIS.md`](report/THESIS.md) | the living thesis: one chapter per experiment + the evidence ledger |
| [`report/literature-survey.md`](report/literature-survey.md) | foundations, arguments for/against, proposed tests, verified bibliography |
| [`report/BACKLOG.md`](report/BACKLOG.md) | candidate future experiments |
| [`video/outline.md`](video/outline.md) | the long-form final explainer, built from each experiment's clips |
| [`social/series-plan.md`](social/series-plan.md) | how the per-experiment posts roll up into a series |

**How it grows.** When an experiment is finished: (1) add its chapter summary to `THESIS.md`, (2) add its
findings as ledger rows, (3) add its best clip to the final video outline, (4) schedule its thread in the
series plan.
